语音日记系统（左耳）

一个基于 Java+Spring Boot 开发的语音日记记录系统，帮助用户通过语音方式记录日常心情与生活片段。

✨ 功能模块说明

🎤 语音录制模块

音频采集：通过系统麦克风录制用户语音，并将音频文件保存到本地audio目录。

基础存储：实现了音频文件的本地持久化，确保录制的语音可以被保存和后续访问。

📁 项目框架

后端基础：搭建了标准的 Spring Boot 工程结构，包含完整的 Maven 依赖管理与项目配置。

运行环境：兼容 JDK 17+，可通过mvn命令直接编译、启动项目。

🛠️ 技术实现要点

后端：Java 17 + Spring Boot + Maven

音频存储：本地文件系统存储，支持多种常见音频格式

项目管理：Maven 进行依赖管理与项目构建

📌 版本说明
